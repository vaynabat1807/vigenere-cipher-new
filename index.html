ALGORITHM OVERVIEW

How Vigenère Cipher Works

The application converts letters into values from 0 to 25 and applies modular arithmetic for encryption and decryption.

A
LETTER MAPPING

A = 0 … Z = 25

Each alphabetic character is represented by a number from 0 to 25.

🔒
ENCRYPTION

C = (P + K) mod 26

The plaintext value and key value are added modulo 26.

🔓
DECRYPTION

P = (C - K + 26) mod 26

The key value is subtracted from the ciphertext value modulo 26.

🔁
REPEATING KEY

keyIndex % key.length

Modulo makes the key repeat when the message is longer than the key.
